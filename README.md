# Scale-Formation-from-Dissolved-Organic-Matter-in-SAGD-Steam-Generators--Part-II
Raw ESI-P and APPI-P FTICR-MS data (Excel) and statistical code (PCA, K-Means, correlation) for Part II of scale formation from dissolved organic matter in SAGD steam generators. Identified formulas in BFWs, heated BFWs, and generated solids from Athabasca (SAGD) and Cold Lake (CSS), Alberta.
Raw data for ESI-P and APPI-P FTICR-MS analysis of Scale Formation from Dissolved Organic Matter in SAGD Steam Generators- Part II: Alkaline, Neutral, and Sulfur-rich Species Characterized by ESI-P and APPI-P FTICR-MS is provided in two Excel files in this repository. BFWs_ESIP-FTICR-MS.xlsx and BFWs_APPIP-FTICR-MS.xlsx contain identified chemical formulas by ESI-P and APPI-P FTICR-MS, respectively, in boiler feed waters (BFWs), heated BFWs, and the solids generated during heating, for samples from Athabasca (SAGD) and Cold Lake (CSS) facilities in Alberta, Canada. These samples were collected during 2020 and 2021 and were analyzed from 2020 to 2024. The sheet name serves as an ID for each BFW, and the heated ones contain the BFW's ID plus "16". This repository also contains the Python code used for the statistical analyses (PCA, K-Means, and correlation) reported in the paper. This data is the supplementary for [DOI to be added upon publication] and is the companion dataset to Part I (https://doi.org/10.1021/acs.energyfuels.5c01778).
