# Scale-Formation-from-Dissolved-Organic-Matter-in-SAGD-Steam-Generators-Part-II
Raw ESI-P and APPI-P FTICR-MS data (Excel) and statistical code (PCA, K-Means, correlation) for Part II of scale formation from dissolved organic matter in SAGD steam generators. Identified formulas in BFWs, heated BFWs, and generated solids from Athabasca (SAGD) and Cold Lake (CSS), Alberta.
